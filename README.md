# QUOKA 스쿱마켓

쿼카의 AI 스쿱마켓 카드 감상 웹사이트입니다. 팩 개봉, 카드 8종 수집, 카드 뒤집기와 이머시브 영상을 제공합니다.

## 실행

index.html과 assets 폴더를 같은 위치에 둔 채 정적 웹 서버로 실행합니다. GitHub Pages는 main 브랜치의 루트 폴더에서 배포합니다.

## 수업 자료 연결

index.html의 CARDS 배열에서 각 카드의 url에 수업 자료 주소를 입력합니다. 현재 주소는 비어 있어 자료 연결 버튼이 비활성화되어 있습니다.

카드 수집 기록과 효과음 설정은 방문자의 브라우저에 저장됩니다.
